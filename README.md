#  ShoppingHub API

A **.NET Core Web API** for building an e-commerce backend, providing RESTful endpoints for managing products, customers, orders, and shopping-related operations.

## Features

*  RESTful Web API
*  Product management
*  Customer management
*  Order management
*  API-based architecture
*  Swagger/OpenAPI documentation
*  Postman Testing

## Tech Stack

* C#
* .NET Core
* ASP.NET Core Web API
* Entity Framework Core
* SQL Server
* REST API
* Swagger
* Git & GitHub

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Gurpreet1523/shoppinghubapi.github.io.git
cd shoppinghubapi.github.io
```

Restore dependencies:

```bash
dotnet restore
```

Run the API:

```bash
dotnet run
```

Open Swagger to explore the API endpoints.

## Purpose

This project demonstrates **backend development, REST API design, database integration, and .NET Core Web API development**.
